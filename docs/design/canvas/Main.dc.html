How to read this page. Every ratio was computed against the surface it is meant to sit on (OKLCH → sRGB → WCAG relative luminance), not eyeballed. "-strong" tokens are the only ones cleared for body text; "-bright" tokens are fills, icons and large decorative marks only — never small text on their own. "AA" here always means ≥4.5:1 for text, ≥3:1 for the UI-component pairs (borders, focus rings). accent-primary reads amber/rust — a stamped ticket-ink color, not a bright CTA orange — chosen deliberately over a louder hue so it still passes AA as running text, not just as a button fill.
