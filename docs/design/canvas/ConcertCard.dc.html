The stub column is a fixed 92px on any width down to phone — never a bottom strip — because the perforation-and-notch motif is what makes this read as a ticket rather than a generic card, and it survives width changes better than a rounded-corner-plus-left-border treatment would. Multi-band shows join with "+", not a comma list, to keep the co-headline reading distinct from a supporting-act list.
