Setlistify — Design System

06 · Empty, loading, degraded & error states

These four are the normal case here, not the exception — a band with no setlist.fm entry, or a playlist matched at 14 of 19 songs, is a successful run of the product, not a failure. None of them should read as "something is broken."

Iconography stays identical in tone across all four — thin, warm-neutral line icons, never a red/orange "warning triangle" reflex for degraded (that belongs to Error alone). Degraded gets its own visual language entirely — a progress fraction and an amber-free info-blue fill — so 14/19 reads as mostly-done, not half-broken.
