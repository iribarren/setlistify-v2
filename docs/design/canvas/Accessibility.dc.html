44px min height, full width hit area

Applies everywhere, including a visually small badge or icon inside a denser row — pad the tap area, don't shrink it. This is the app-store baseline (iOS HIG 44pt, Android 48dp ≈ 44–48px at typical density) and the floor this system uses across platforms.

One consistent treatment everywhere: a 3px accent-primary ring at 18% opacity plus a 1.5px solid accent-primary edge on the control itself — visible on top of any surface, light or dark, and never color-only (the ring's geometry is what registers, so it still reads for color-blind users). Keyboard focus and touch/mouse focus use the same ring; there is no keyboard-only variant to fall out of sync.
