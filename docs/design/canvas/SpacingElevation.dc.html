Elevation

flat
elevation-0
border only, no shadow
raised
elevation-1
card, list row on hover
floating
elevation-2
dropdown, toast
overlay
elevation-3
modal, bottom sheet

Single-layer, low-blur shadows only — two stacked shadows max, no colored glows, no inset+outset combinations. This is what survives react-native-web unchanged: it maps directly to RN's shadowColor/shadowOffset/shadowOpacity/shadowRadius on iOS and elevation on Android without a second, divergent style branch. elevation-0 is the default for flat surfaces in dark mode, where a shadow reads as nothing against near-black — lean on the border-strong token instead.
