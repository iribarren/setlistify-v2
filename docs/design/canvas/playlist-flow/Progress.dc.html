Designing the wait. Three named steps replace a single spinner so the wait reads as work happening, not a hang — "Found the setlist" resolves almost immediately (cheap, reassuring), the matching step carries a live X-of-Y counter that ticks up song by song (the only part that takes real time), and "Saving the playlist" is a fast final beat. The ring is indeterminate, not a percentage — song-matching time varies with catalog lookups, so a precise progress bar would either stall or lie. "You can leave this screen" is explicit because a 25-song run can run past what someone will sit and watch; leaving does not cancel it (D-appropriate for later prompts to implement).
