25 decisions become 3. This is the answer to the brief's stated biggest risk. Confident single matches (22 of 25 here) never surface as a decision at all — they collapse into one green summary band, expandable for anyone who wants to audit them, but never demanding a tap. Only genuinely ambiguous songs get a card: a version conflict, an only-live-version-exists case, and a song with three real candidates. Each card pre-selects Setlistify's top pick (marked "Top pick" / "Only match") so confirming the whole screen with zero taps is a legitimate path — the user is reviewing pre-made decisions, not making 25 from scratch.
