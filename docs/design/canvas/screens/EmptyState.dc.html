Why a ticket-stub icon, not a generic illustration. The empty state reuses the app's one recurring visual motif (the perforated ticket from the concert card) rather than an unrelated stock illustration, so it reads as "this app, with nothing in it yet" rather than a generic SaaS placeholder. Single CTA, no secondary "browse examples" link — there's nothing to browse until they add one. This state also covers "all filtered out" only in the sense that a genuinely-zero list always reaches for it; a *filtered-to-zero* list (e.g. Past with nothing yet) uses a smaller inline variant, not this full-screen one — shown in States, page 3.
